# F5 AI Security - Surepath.ai Lab

Welcome to the F5 Surepath.ai repository. This workshop is designed for F5ers, partners, and customers to discover and learn about the capabilities of the **F5 Surepath.ai** solution.

In the Class 1, everything in this lab environment is pre-configured so you can easily explore and experience Surepath.ai's capabilities:

* **Interception**
* **Detection**
* **Masking** (PII, Financial data, etc.)
* **Blocking**
* **Control**
* **Reporting**

---

## Lab Overview & Demo Flow

The lab provides a hands-on walk-through using a pre-configured Windows 11 RDP environment.

### 1. Accessing the Lab Environment
* **Windows 11 RDP**: Log in to the desktop workspace.
* **Chrome Browser**: Open pre-saved bookmarks (e.g., Surepath AI Ready check, F5 Surepath Admin Portal, ChatGPT, Claude, and Gmail) with pre-configured Single Sign-On (SSO).

### 2. Executing Demo Scenarios
Send targeted prompts to ChatGPT or Claude to test real-time security enforcement:
* **Data Redaction & PII Masking**: Redact names, emails, and phone numbers dynamically from marketing briefs and resume reviews.
* **Financial Data Protection**: Mask sensitive financial data and loan applications.
* **Custom Intent Classifiers**: Test blocking actions and match confidence scores on prohibited prompts (e.g., Quality of Earnings reports).
* **Gambling Classifier**: Test instant blocking of gambling-related content.
* **Model Context Protocol (MCP) Intercept**: Block and redact sensitive GitHub repository details dynamically within Claude Desktop.

### 3. Verification & Auditing
* **Client-Side Enforcement**: Observe real-time blocking and masking directly inside the ChatGPT or Claude UI.
* **Admin Portal Visibility**: Access the F5 Surepath.ai Admin Console to view user activity, drill down into logs, and inspect detailed warning event states.
